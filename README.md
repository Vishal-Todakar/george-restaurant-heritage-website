
# George Restaurant Heritage Website

A premium heritage-themed restaurant website inspired by the legendary George Restaurant located in Camp, Pune.

This project focuses on creating a modern digital experience while preserving the nostalgic old-school Mughlai restaurant atmosphere and legacy branding.
